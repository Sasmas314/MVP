# Тестирование сервиса

## Цель

Проверить:
- работает ли сервис корректно
- удобно ли им пользоваться

---

# Фокус-группа (3 человека)

1. **Новичок** — почти без технических знаний  
2. **Обычный пользователь** — работал с документами  
3. **Более опытный пользователь** — понимает, как работают такие системы  

---

# Сценарий теста

Каждый участник выполняет:

1. Открыть приложение  
2. Загрузить 2–3 документа (PDF или изображения)  
3. Нажать «Распознать документы»  
4. Проверить данные  
5. Исправить 1–2 поля вручную  
6. Скачать Excel
