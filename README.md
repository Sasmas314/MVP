# Expense Parser MVP

Веб-приложение на **Python + Streamlit** для распознавания транспортных и гостиничных документов:

- билеты на поезд
- авиабилеты
- такси
- документы на проживание / бронирование / чеки отелей

Приложение принимает файлы в форматах:

- `PDF`
- `JPG`
- `JPEG`
- `PNG`

Далее приложение пытается извлечь из документов нужные данные с помощью **vision-language модели**  
**`qwen/qwen3-vl-8b`**, развернутой локально через **LM Studio**.

После распознавания пользователь может:

- проверить найденные данные
- вручную исправить ошибки
- увидеть, каких полей не хватает
- выгрузить итоговый **Excel-отчет** для бухгалтерии

---

# Что умеет проект

Приложение умеет:

- загружать **несколько файлов за один раз**
- обрабатывать **многостраничные PDF**
- сначала пытаться извлечь текст из PDF обычным способом
- если текст не извлекается, отправлять страницы PDF как изображения в VLM-модель
- извлекать поля:
  - тип документа
  - имя
  - фамилия
  - отчество
  - дата отправления
  - дата прибытия / прилета
  - сумма
  - валюта
  - поставщик / перевозчик / отель
  - маршрут
  - номер билета / брони
  - дата оплаты
- **не придумывать отсутствующие данные**
- явно показывать, каких полей нет
- давать возможность вручную редактировать результат
- формировать итоговый Excel-файл

# Как работает приложение

## Общая логика

1. Пользователь запускает веб-приложение.
2. Загружает один или несколько документов.
3. Программа определяет тип файла.
4. Если файл — `PDF`, приложение:
   - пытается извлечь текст со всех страниц
   - если текст есть, отправляет текст в модель
   - если текста нет или он плохого качества, конвертирует страницы в изображения и отправляет в модель
5. Если файл — `PNG/JPG/JPEG`, изображение сразу отправляется в модель.
6. Модель возвращает структурированные данные в формате JSON.
7. Приложение показывает результат в таблице.
8. Пользователь при необходимости вручную исправляет поля.
9. Программа формирует Excel-отчет.

# Технологии

В проекте используются:

- **Python 3.10+**
- **Streamlit** — веб-интерфейс
- **Pandas** — работа с таблицами
- **OpenPyXL** — экспорт в Excel
- **PyMuPDF** — извлечение текста и изображений из PDF
- **Pillow** — обработка изображений
- **Requests** — запросы к LM Studio API
- **python-dateutil** — нормализация дат
- **LM Studio** — локальный сервер модели
- **Qwen/Qwen3-VL-8B** — vision-language модель
